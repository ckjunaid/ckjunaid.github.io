# junaid-portfolio

Personal portfolio of Junaid C K. A single static page (`index.html`) with no build step.

## Add your files
- `assets/resume.pdf`: your CV. The Résumé buttons link here.
- `assets/me.jpg`: your portrait, ideally 4:5 (for example 800×1000). It appears in the About section automatically.

## Publish on GitHub Pages
1. Create a repository named `ckjunaid.github.io`.
2. Upload `index.html`, `README.md` and the `assets/` folder.
3. Go to Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Open https://ckjunaid.github.io after about a minute.
